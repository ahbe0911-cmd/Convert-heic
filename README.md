# Convert HEIC to JPG (Android)

برنامه اندرویدی سبک برای تبدیل عکس‌های HEIC/HEIF به JPG.

## امکانات
- انتخاب یک یا چند عکس HEIC/HEIF
- تبدیل کاملاً آفلاین روی گوشی
- حفظ رزولوشن اصلی
- حالت کیفیت حداکثری (JPEG Quality 100)
- حالت هدف حدود 480KB با حفظ رزولوشن و اولویت کیفیت
- ذخیره JPGها در پوشه دلخواه
- ساخت ZIP شامل همه JPGهای تبدیل‌شده
- بدون دسترسی اینترنت و بدون مجوز گسترده حافظه

## نکته درباره 480KB
رسیدن دقیق به 480KB بدون هیچ افت کیفیت برای همه عکس‌ها از نظر فنی قابل تضمین نیست. در حالت 480KB برنامه رزولوشن را تغییر نمی‌دهد و فقط کیفیت JPEG را تا حد امن تنظیم می‌کند. اگر رسیدن به 480KB باعث افت زیاد شود، کیفیت اولویت دارد و فایل می‌تواند بزرگ‌تر بماند.

## ساخت APK
از تب **Actions** ورک‌فلو **Build Android APK** را باز کنید. بعد از هر Push روی main، APK دیباگ ساخته و به‌صورت Artifact با نام **Convert-heic-debug-apk** قرار می‌گیرد.
